# 馆藏研究结论发布链

记录馆藏器物、研究证据、竞争性解释和各渠道公众说明版本，使展签、课程与出版物使用**可追溯、经学术流程门禁、不可被旧内容降级**的研究结论。

## 领域规则

- **证据分储**：器物特征、出土背景、检测记录、文献引文、研究者观点五类证据各自独立存档（`src/domain/evidence-store.js`），修订只能引用、不能改写证据。
- **竞争解释并存**：同一主张下多种解释同时保留，每个修订只标注倾向，不删除对立解释。
- **修订账本**：结论在 `possible（可能）/ confirmed（已证实）/ withdrawn（已撤回）` 之间调整时，必须追加**带理由**的新修订；旧修订不可覆盖。状态迁移受限（撤回后只能凭新证据回到“可能”，不能直接翻案为“已证实”）。
- **学术流程门禁**：只有走完渠道指定流程（如同行评审＋策展委员会）的修订才能发布到该渠道；并行评审意见独立归档，**未采纳意见永久保留**。
- **紧急勘误**：可走渠道紧急流程（如值班馆长）先止损，发布后强制补走常规流程。
- **渠道展签只追加**：每个渠道的展签历史 append-only，旧展签永不被覆盖；当前展签由日志末尾导出。
- **通知与回执**：新修订自动通知所有仍在分发旧版的渠道；合作机构离线确认后的**迟到回执只记账**，版本落后标记 `late_ignored`，且任何旧修订都不能再发布（单调版本护栏）。
- **译文锁**：译文必须锁定同一事实版本（修订标识＋版本号），旧修订译文不得用于新修订。
- **查询**：公众得到当前表述与证据边界；内部人员可按历史日期还原各渠道当天展陈文字、批准者与未采纳意见。

## 目录

- `fixtures/seed.json` — 陶俑器物、旱罗盘主张、五类证据、两种竞争解释、v1 旧结论与三渠道旧展签。
- `src/domain/` — evidence-store / revision-ledger / review-office / publication-channel / translation-registry / service（门面）。
- `src/scenario.js` — 端到端叙事：并行评审降级 v2 → 紧急勘误撤回 v3 → 外借离线延迟同步 → 迟到回执不降级 → 全渠道收敛。
- `test/` — 领域规则单元测试与收敛/可追溯性端到端测试。

## 运行

```bash
npm test            # 11 项规则与场景测试
node src/scenario.js  # 打印叙事时间线、公众查询、内部历史还原、官网展签追加日志
```
